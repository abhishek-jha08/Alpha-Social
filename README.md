# AlphaProject2: Social Media Platform

## 📖 Description
A lightweight, full-stack social media web application built with Node.js. This platform is designed to let users connect and share updates. It features a custom backend integrated with a local database to seamlessly handle data storage, alongside a clean, responsive frontend.

## ✨ Features
*   **Data Persistence:** Securely stores data and handles interactions using a local database (`social.db`).
*   **Dynamic Frontend:** A clean, intuitive user interface built with standard web technologies (HTML, CSS, JavaScript).
*   **Custom Backend:** Node.js server configured to process client-side requests and manage application logic.

## 🛠️ Tech Stack
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript
*   **Backend:** Node.js (with Express.js)
*   **Database:** SQLite (implied via `social.db`)

## 🚀 Getting Started
To get a local copy up and running, follow these simple steps.

### Prerequisites
*   [Node.js](https://nodejs.org/) installed on your machine.
